1.1 Componentes Internos

1.1.1 CPU

A Unidade Central de Processamento (CPU) é o cérebro do computador, responsável por interpretar e executar instruções de software e hardware.

1.1.2 Armazenamento

Os dispositivos de armazenamento, como discos rígidos (HDs) e unidades de estado sólido (SSDs), são responsáveis por salvar dados e programas de forma permanente.

1.1.3 Memória

A memória RAM (Memória de Acesso Aleatório) armazena temporariamente dados que estão sendo utilizados pelo processador, permitindo acesso rápido e eficiente.

1.1.4 Fonte de Alimentação

A fonte de alimentação converte a energia elétrica da rede em níveis adequados para alimentar os componentes internos do computador.

1.2 Componentes Externos

1.2.1 Teclado

O teclado é um dispositivo de entrada que permite ao usuário inserir dados e comandos no computador.

1.2.2 Monitor de Vídeo

O monitor exibe informações visuais ao usuário, permitindo a interação com o sistema operacional e aplicativos.

1.2.3 Mouse

O mouse é um dispositivo apontador que permite ao usuário interagir com elementos gráficos na tela do computador.

1.2.4 Impressora

A impressora é um dispositivo que produz uma cópia física de documentos digitais em papel.

1.2.5 Plotter

O plotter é um dispositivo de impressão utilizado para produzir gráficos de grande escala, como plantas arquitetônicas e desenhos de engenharia.

1.2.6 Scanner

O scanner digitaliza documentos físicos, convertendo-os em formatos digitais para armazenamento ou edição no computador.

1.2.7 Gabinete

O gabinete abriga e protege os componentes internos do computador, além de auxiliar na ventilação e organização do hardware.

1.2.8 Web Cam

A webcam é uma câmera digital conectada ao computador que permite a captura de imagens e vídeos em tempo real, geralmente utilizada para videoconferências.

1.2.9 Caixas de Som

As caixas de som são dispositivos de saída de áudio que reproduzem sons gerados pelo computador, como músicas, alertas e outros sons do sistema.
